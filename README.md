# Webshop

A full-stack e-commerce application built with Java Spring Boot and React. The application allows users to browse products, manage a shopping cart, place orders, and manage their accounts. Administrators have access to additional functionality for managing products and users.

This project was originally developed as part of a group assignment during my Java Software Developer training at ITvitae. I have continued working on the project to improve its functionality, maintainability, and overall structure.
